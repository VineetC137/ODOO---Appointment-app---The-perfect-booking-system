DATABASE SETUP INSTRUCTIONS
===========================

You need to create the PostgreSQL database before running migrations.

Option 1: Using pgAdmin (GUI)
------------------------------
1. Open pgAdmin
2. Connect to your PostgreSQL server
3. Right-click on "Databases"
4. Select "Create" → "Database"
5. Enter name: appointment_booking
6. Click "Save"

Option 2: Using psql (Command Line)
------------------------------------
1. Open Command Prompt or PowerShell
2. Navigate to PostgreSQL bin directory (usually C:\Program Files\PostgreSQL\14\bin\)
3. Run: psql -U postgres
4. Enter your PostgreSQL password
5. Run: CREATE DATABASE appointment_booking;
6. Run: \q to exit

Option 3: Using SQL Query Tool
-------------------------------
1. Open any PostgreSQL client (DBeaver, DataGrip, etc.)
2. Connect to your PostgreSQL server
3. Run: CREATE DATABASE appointment_booking;

After creating the database:
----------------------------
1. cd appointment-booking-mvp/backend
2. npm run db:migrate
3. npm run db:seed
4. npm run dev
